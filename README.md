# Quantification-of-H9c2-cell-differentiation-
Matlab script associated to the Morphological Analysis (Figure 2) in York et al., 2024. This serves as a reference to implement morphological analysis including length, area, perimeter, and eccentricity for cells that are irregularly shaped and close in proximety.
A R script for graphing the results via a Superplot is also provided which was used in Figures 2, 3, and 4.
